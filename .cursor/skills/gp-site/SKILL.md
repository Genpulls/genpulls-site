# gp-site

Follow this skill on every Generational Pulls marketing-site change in this repository (`genpulls-site`). Read it before editing pages, styles, assets, or pull requests.

The public site is static HTML and CSS (GitHub Pages). Keep edits inside that model.

## Rules

1. Never put Jason Ashford's personal name on the public site. Do not add it to HTML, CSS, alt text, metadata, structured data, image filenames, or any other file visitors receive. The name belongs only in private agent instructions such as this skill.

2. Keep the brand Generational Pulls, the handle @genpulls_au, and the domain genpulls.au. Do not rename the business, swap the handle, or invent a different public domain.

3. When restyling, use a LowPop-inspired visual direction: a clean reseller aesthetic, high-contrast product focus, and minimal chrome. Product stays primary. Navigation, decoration, and other chrome stay quiet.

4. Open a draft pull request. Do not merge, and do not mark the pull request ready in order to land it, without an explicit yes from Jason.

5. Prefer small, focused pull requests. One concern per PR. Do not bundle unrelated page, copy, and infrastructure edits.

6. Leave existing HTTPS, GitHub Pages, and DNS alone unless the task names them. Do not edit `CNAME`, Pages settings, certificates, nameservers, or DNS records as a side effect of a content or design task.

## Workflow

- Branch from `main`.
- Change only what the task asks for.
- Open the pull request as a draft.
- Stop and wait for Jason's explicit yes before any merge.
